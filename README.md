\# S.S. Agarwal Smart Shop



\### Smart Shop Management System for S.S. Agarwal Cloth Merchant



S.S. Agarwal Smart Shop is a web-based shop management system designed for \*\*S.S. Agarwal Cloth Merchant\*\*.



The system helps the shop administrator manage employees, attendance, salary transactions, work assignments, and other day-to-day shop management activities through a centralized application.



\---



\## 🚀 Features



\### 👨‍💼 Admin Management

\- Admin login

\- Employee management

\- Create, edit and delete employees

\- Employee ID generation

\- Employee activation/deactivation

\- Monthly salary management



\### 👷 Employee Management

\- Employee login

\- Temporary password based first login

\- Permanent password creation

\- Employee profile information

\- Role-based access



\### 📅 Attendance Management

\- Admin can mark employee attendance

\- Attendance statuses:

&#x20; - PRESENT

&#x20; - HALF DAY

&#x20; - ABSENT

\- Employees can view their own attendance records

\- Monthly attendance information



\### 💰 Salary Management

\- Monthly salary tracking

\- Salary payment records

\- Advance amount tracking

\- Advance deduction tracking

\- Salary balance calculation

\- Transaction history



\### 📋 Work Assignment

\- Admin can assign work to employees

\- Work title and details

\- Assignment date

\- Employees can view assigned work

\- Employees can mark assignments as read



\### 🔐 Authentication

\- Firebase Authentication integration

\- Firebase Firestore database

\- OTP verification flow prepared for employee mobile verification

\- Temporary password and first-login password setup
